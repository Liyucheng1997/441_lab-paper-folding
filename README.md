# 折纸学堂

跟着可以旋转的 3D 动画学折纸和剪纸。

## 怎么打开

双击 `启动.bat`（第一次会自动安装依赖），浏览器会自动打开。或者手动运行：

```bash
npm install
npm run dev
```

## 内容

**折纸（10 个）**

| 难度 | 教程 |
| --- | --- |
| 入门 | 小狗脸、小猫脸、纸杯、爱心 |
| 初级 | 纸飞机、东南西北、鲸鱼、天鹅 |
| 中级 | 纸船 |
| 高级 | 千纸鹤 |

**剪纸（6 个 + 自由创作）**：对称爱心、拉手小人、一刀五角星、八瓣窗花、六角雪花、十六瓣团花；自由剪纸可以选折法后自己画。

## 操作

- 拖动旋转模型，滚轮缩放
- `←` `→` 切换步骤，空格播放 / 暂停
- 进度条可以拖动，慢慢看一步里纸是怎么动的
- 蓝色虚线是向前折（谷折），灰色点划线是向后折（山折）

## 代码结构

- `src/engine/fold.js`：折叠引擎。纸是一组带位姿和层号的多边形，每步按折线切分、翻转、重新排层
- `src/engine/viewer.js`：Three.js 播放器和缩略图
- `src/models/origami.js`：折纸教程数据（每一步的折线、选哪几层、说明文字）
- `src/cut/`：剪纸的折法、图案，以及把剪掉的形状映射回整张纸的贴图
- `test/check.mjs`：`npm run check` 自检，每一步折完纸都不能“撕开”

## 添加新教程

在 `src/models/origami.js` 里照着现有模型加一个对象，放进 `ORIGAMI` 数组，然后运行 `npm run check`。
